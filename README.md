💼 Profile Card UI

A responsive Profile Card / Job Openings UI built with React.js. This project demonstrates the use of reusable React components, props, and dynamic rendering to display multiple job cards in a clean and modern interface.

🚀 Features Reusable React components Dynamic rendering using map() Company logo display Job title and company name Salary and location details Employment type and experience tags Apply Now button Save icon using Font Awesome Responsive and modern UI 🛠️ 
Tech Stack-
React.js
JavaScript (ES6)
HTML5
CSS3
Font Awesome 📂
